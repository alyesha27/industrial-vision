# Dataset Card: PPE (каска, голова без каски, жилет)

| Поле | Значение |
|---|---|
| Название набора | `Robbin123/ppe-dataset` (Hugging Face), версия — на момент загрузки 25.10.2026 |
| Назначение | Контроль СИЗ (F-05): обнаружение каски и жилета, а также головы без каски для события `ppe_helmet_missing` |
| Формат | YOLO (изображения `.png`/`.jpg` + `.txt` с bbox), каталоги `train/`, `val/`, `test/` |

## Классы

| ID | Класс | Определение |
|---|---|---|
| 0 | `helmet` | видимая защитная каска на голове |
| 1 | `head` | голова без каски (нарушение) |
| 2 | `vest` | видимая область светоотражающего жилета |

## Источники и разметка

Набор опубликован на Hugging Face и, по описанию автора, собран из нескольких источников с конвертацией разметки из VOC в YOLO. Имена файлов вида `ds1_hard_hat_workers<N>` указывают на источник «hard hat workers». Собственная разметка не выполнялась. Персональные данные не добавлялись.

## Ограничения и известные смещения

- **Риск data leakage.** Файлы с соседними номерами одного источника попали в разные выборки (`workers1003`, `1005` — train; `1004` — val; `0`, `1000`, `1001` — test), а mAP50 на val достигает 0,839 уже после первой эпохи. Проверка дубликатов и разбиение по сценам не выполнялись; метрики следует считать верхней оценкой.
- Класс `head` значительно реже `helmet` и `vest`.
- Преобладают дневные сцены строительных площадок; ночные сцены, дальние объекты, осадки и сильные перекрытия представлены слабо [проверить по набору].
- Набор не содержит видео: временное поведение (мерцание детекций между кадрами) не оценивалось.
