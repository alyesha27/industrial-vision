# Результаты тестирования

В проекте выполнено сравнение двух вариантов модели обнаружения объектов:
`yolo26n.pt` и `yolo26n.onnx`.

Для каждого варианта обработано 200 кадров. Во время тестирования измерялись
скорость обработки, загрузка процессора, использование оперативной памяти
и время работы отдельных компонентов конвейера.

## Результаты

| Показатель | yolo26n.pt | yolo26n.onnx |
|---|---:|---:|
| Количество кадров | 200 | 200 |
| Скорость, FPS | 13.5 | 30.1 |
| Среднее время конвейера, мс | 74.3 | 33.2 |
| Загрузка CPU, % | 19.1 | 89.3 |
| Использование RAM, МБ | 459 | 514 |
| Размер модели, МБ | 5.5 | 9.9 |

## Вывод

В проведённом тесте модель ONNX показала более высокую скорость обработки:
30.1 FPS против 13.5 FPS. При этом её использование сопровождалось большей
загрузкой процессора и расходом оперативной памяти.

Результаты относятся к конкретному запуску на данной системе. При использовании
другого оборудования, видеопотока или настроек показатели могут отличаться.

Подробные измерения приведены в файлах [benchmark.md](benchmark.md)
и [benchmark_onnx.md](benchmark_onnx.md).
