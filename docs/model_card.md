# Model Card: `ppe.pt` (контроль СИЗ)

| Поле | Значение |
|---|---|
| Модель | YOLO26n (Ultralytics 8.4.188), дообучение с предобученного `yolo26n.pt` |
| Задача | Object detection, 3 класса: `helmet`, `head`, `vest` |
| Вход | RGB-кадр, масштабирование до 640 px (letterbox), нормализация внутри Ultralytics |
| Данные | `docs/dataset_card.md` (Robbin123/ppe-dataset) |
| Файл весов | `models/ppe.pt` (5,2 МБ; в Git не хранится, см. «Получение весов») |

## Обучение (эксперимент E01)

| Параметр | Значение |
|---|---|
| Среда | Google Colab, GPU Tesla T4 |
| Эпохи / batch / imgsz | 30 / 16 / 640 |
| Оптимизатор | AdamW (lr подобран автоматически: 0,001429) |
| Аугментации | штатные Ultralytics (mosaic, HSV, fliplr и др.), `close_mosaic=10` |
| Seed | 0 (`deterministic=True`) |
| Время обучения | около 1,4 ч |
| Размер модели | 2 390 221 параметр в объединённом виде, 5,4 GFLOPs |

Повторный запуск с теми же параметрами дал те же метрики.

## Производительность

На Tesla T4: 0,5 мс предобработка, 3,2 мс инференс, 2,0 мс постобработка на изображение. На CPU Intel Core i7-13620H: [заполнить из `docs/benchmark_*.md`].

## Ограничения

- Метрики могут быть завышены из-за возможной утечки данных между выборками (см. Dataset Card).
- Класс `head` редок: больше пропусков нарушения «нет каски».
- Принадлежность СИЗ человеку определяется по центру рамки внутри рамки человека; при перекрытии людей возможны ошибки. Люди ниже 120 px не анализируются.
- Не проверялась работа ночью, на большом расстоянии и в дождь.

## Применение в конвейере

Запускается на каждом втором кадре (`extra_every: 2`) и вместе с рамками людей даёт события `ppe_helmet_missing` и `ppe_vest_missing` после подтверждения N из M (3 из 5) и cooldown 10 с.

## Получение весов

`best.pt` из `runs/ppe_e01/weights/` на Google Диске автора; положить в `models/ppe.pt`. Воспроизведение: команда обучения и `data.yaml` приведены в отчёте, набор скачивается `snapshot_download("Robbin123/ppe-dataset", repo_type="dataset")`.
